## 🚀 Featured Projects

### 🔍 ScanLens — Security Scanning SaaS

Full-stack security scanner with AI-powered vulnerability assessment and subscription management.

**Features:**
- 🔐 Multi-Engine Scanning — SSL/TLS, HTTP headers, cookies, CORS policy analysis
- 🤖 AI Remediation — OpenAI-powered fix recommendations for detected vulnerabilities
- 💳 Subscription Tiers — Free / Pro / Extra with feature gating
- 👨‍💼 Admin Dashboard — User management, subscription control, payment history
- ⚡ Real-time Processing — Background job queue with Redis + Bull
- 📊 Detailed Reports — Security score, deep audit with visual breakdowns
- 🔒 JWT Auth — Secure authentication with refresh tokens

**Tech:** `Next.js 15` · `NestJS` · `PostgreSQL` · `Prisma` · `Redis` · `Bull` · `OpenAI API`

### 📚 e-School Admin — Student Administration System

Dual-role platform for teachers and students with 2FA security and interactive analytics.

**Features:**
- 👨‍🏫 Teacher Dashboard — Student management, grade entry, quiz creation, attendance tracking
- 🎓 Student Portal — Digital ID card, grade visualization, attendance calendar, quiz results
- 🔐 OTP & 2FA Security — Time-limited email verification codes for all auth flows
- 🛡️ Brute-Force Protection — Rate limiting + failed attempt tracking
- 📈 Interactive Analytics — Recharts-powered Bar/Pie/Area charts for performance tracking
- 🍪 HttpOnly Cookies — XSS-resistant JWT session management
- 🧪 Automated Testing — Jest + Supertest integration & security test suites

**Tech:** `Next.js 14` · `Express 5` · `PostgreSQL` · `MUI` · `Recharts` · `JWT` · `Nodemailer`
